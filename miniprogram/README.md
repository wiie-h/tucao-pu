# 吐槽铺 · 微信小程序（云开发版）

同一套吐槽铺，做成了小程序。用的是**微信云开发**，所以：

- 不需要服务器
- 不需要备案域名
- 不需要从头写后端（云函数 + 云数据库）
- 免费额度对一个小站足够（云函数调用和数据库读写在免费额度内）

---

## 一、你需要的两样东西

### 1. 小程序 AppID（必须，免费）

1. 打开 https://mp.weixin.qq.com → 右上角「立即注册」→ 选 **小程序**
2. 用一个**没注册过公众号/小程序**的邮箱注册
3. 主体类型选 **个人** 就行（要身份证 + 微信扫脸）
4. 注册完成后，在「开发管理 → 开发设置」里能看到 **AppID**，把它复制下来

> 个人主体也能开发、能预览、能用体验版。唯一的限制在**正式发布**那一步，见第五节。

### 2. 微信开发者工具（必须，免费）

下载地址：https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html

装好后用**注册小程序的微信**扫码登录。

---

## 二、把项目跑起来（约 5 分钟）

### 第一步：导入项目

1. 开发者工具 → 「+」→ **导入项目**
2. 目录选这个 `miniprogram` 文件夹（就是你看到 `project.config.json` 的那一层）
3. AppID 填你刚复制的
4. 点「导入」

第一次打开会提示 `project.config.json` 里的 AppID 还是占位符 —— 导入时填了就会自动替换。

### 第二步：开通云开发

1. 开发者工具顶部点 **「云开发」** 按钮
2. 按提示开通（选免费的就行），创建一个环境，名字随便，比如 `tucao`
3. 环境创建好之后不用做别的 —— 代码里用的是「当前环境」，不需要填环境 ID

### 第三步：部署云函数

1. 左侧文件树里找到 `cloudfunctions` → 右键 `api` 文件夹
2. 选 **「上传并部署：云端安装依赖（不上传 node_modules）」**
3. 等下方提示部署成功

### 第四步：点一下「编译」

模拟器里应该就能看到吐槽墙，墙上有一条「站长」的欢迎帖。

如果显示「连不上服务器」，八成是云函数没部署成功，回到第三步重来一次，或右键 `api` 选「查看云端日志」看报错。

---

## 三、数据库会自动建好

**你不需要手动建集合**。第一次调用云函数时，它会自动创建 `posts`、`shreds`、`reports` 三个集合，并写入一条站长欢迎帖。

想清空数据重新开始：云开发控制台 → 数据库 → 把 `posts` 里的记录删掉即可（下次调用会自动补上欢迎帖）。

### 建议手动加两个索引（数据多了会快很多）

云开发控制台 → 数据库 → `posts` → 索引管理：

| 索引名 | 字段 | 类型 |
| --- | --- | --- |
| `createdAt_desc` | `createdAt` 降序 | 非唯一 |
| `openid_createdAt` | `openid` 升序 + `createdAt` 降序 | 非唯一 |

不加也能跑，只是数据上千条以后会慢一点。

## 四、怎么给朋友用（不用审核）

1. 开发者工具右上角点 **「上传」**，填个版本号比如 `1.0.0`
2. 打开 https://mp.weixin.qq.com → 「管理 → 版本管理」
3. 在「开发版本」里点 **「选为体验版」**
4. 「成员管理 → 体验成员」里加上你朋友的微信号（最多 100 人）
5. 把体验版二维码发给他们，他们扫码就能用

**体验版不需要审核**，功能跟正式版完全一样。日常自己用、给朋友用，到这一步就够了。

---

## 五、关于正式发布（重要）

正式发布要走微信审核，这里有两条硬规定：

1. **UGC（网友能公开发言）类小程序，主体必须是企业或个体工商户**。个人主体的账号提交这类内容，大概率被驳回。
2. 审核会检查：有没有举报入口、有没有内容安全检测、有没有用户协议。

好消息是这两点代码里都做了：

- 「举报这条」在每条吐槽的详情页里，举报数据进 `reports` 集合
- 发帖和评论都会先过微信官方的 `security.msgSecCheck` 内容安全检测，不通过的进 `pending` 状态、不公开
- 再叠加一层本地的广告/联系方式过滤（手机号、微信号、网址、刷单博彩类词）

**如果你要正式发布**：去把小程序主体升级成个体工商户（个体户执照几百块、一周左右能办下来），或者用已有公司的资质注册一个新主体。个人主体建议就停在体验版。

## 七、和网页版的关系

网页版（仓库根目录那套）和小程序版**共用同一套设计**（配色、心情、标签、便利贴样式、碎纸机的概念），但代码是两份：

- 网页版：Node 服务 + SQLite（或 Cloudflare Workers + D1）
- 小程序版：云函数 + 云数据库

两边数据是**独立的**，不互通。如果你希望它们共用一个后端，小程序这边也能改成用 `wx.request` 去打网页版的接口 —— 但那样就必须有一个**已备案**的域名，而且要在小程序后台把域名加进白名单。所以现阶段用云开发是最省事的。

## 八、目录结构

```
miniprogram/                     ← 用开发者工具导入这一层
├── project.config.json          项目配置（AppID 填这里）
├── miniprogram/                 小程序前端
│   ├── app.js / app.json / app.wxss
│   ├── pages/
│   │   ├── wall/                吐槽墙（列表、筛选、同感）
│   │   ├── write/               写吐槽 + 碎纸机
│   │   ├── detail/              详情 + 接话 + 举报
│   │   └── mine/                我的 + 换昵称
│   └── utils/
│       ├── moods.js             心情、标签、时间格式化
│       └── api.js               调用云函数的封装
└── cloudfunctions/
    └── api/                     后端云函数（一个函数顶全部接口）
        ├── index.js
        └── package.json
```
